# Rust Playground

A simple Rust project created as a playground for experimenting with Rust code. This is the default "Hello, World!" application generated by `cargo new playground`.

## Getting Started

### Prerequisites

Ensure you have Rust and Cargo installed. You can install them via [rustup](https://rustup.rs/).

### Clone the Repository

```bash
git clone https://git.vsulimov.com/rust-playground.git
cd rust-playground
```

### Run the Project

```bash
cargo run
```

This will compile and execute the default `main.rs`, printing "Hello, world!" to the console.

## Project Structure

- `src/main.rs`: The main Rust source file containing the default "Hello, world!" program.
- `Cargo.toml`: Configuration file for the Rust project, specifying dependencies and metadata.
